1. To start a Celery Worker (aitm Module):

    python -m celery -A AIToolSuite_prod worker -l info -P solo

2. To start a Celery Beat (aitm Module):

    python -m celery -A AIToolSuite_prod beat -l info

3. To start Watchdog (scanner Module):

    python manage.py watch_hitlogs

4. Remember to start Redis Service and Docker Engine as well.

5. Set OLLAMA_HOST=0.0.0.0 as environment variable in the system.

6. To map data from xlsx file to database (scanner_results Module):

    python manage.py import_probe_mapping 'C:\Users\Utkarsh\Downloads\data-1.xlsx'
